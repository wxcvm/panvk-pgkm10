# 源码性能检查报告（PERFORMANCE-REVIEW，最终版）

日期：2026-10-20
范围：本仓库补丁序列 019–039 与模块脚本（模块当前已停用，本报告用于最终版归档）。

## 方法

1. 逐补丁审查新增代码，按调用频率分类：
   - **热路径**（每次图像创建 / 每次 AHB 导入 / 每帧或每次提交）
   - **一次性路径**（初始化、属性读取、导入时）
2. 检查所有新增日志（`mesa_logi`）、属性读取（`__system_property_get`）、
   调试开关与 tracing 代码的位置与开销。
3. 对照已采集的实测数据（1.0.0 系列 A/B、200 s 压力测试）。

## 审查结论

| 补丁 | 作用 | 调用频率 | 性能结论 |
|---|---|---|---|
| 019 | ANB fd 发现 | 每次 AHB 导入一次 | 可接受（导入路径） |
| 020 | 跳过 DRM sync payload 拷贝 | 每次提交 | 性能收益（省拷贝） |
| 021 | sync file waiter 生命周期 | 提交/等待路径 | 修复，无额外开销 |
| 022–025、027–029 | 诊断 tracing / 日志 | 部分在提交、队列、呈现路径 | **仅诊断用途，最终构建排除** |
| 026 | gralloc mapper 优先查询 | 每次 AHB 导入一次 | 功能性修复，无帧内开销 |
| 030 | Android acquire 一次性重放 | 每次 acquire 一次布尔/静态判断 | 可忽略；仅在调试属性开启时生效 |
| 031 | kbase 导入一致性 | 每次导入属性读取 | 属性值静态缓存，仅导入时生效 |
| 032 | AFBC 开关属性 | 图像创建时一次静态读取 | 可忽略 |
| 033 | AFBC 线性导入开关 | 同上 | **发现：每次 AFBC 图像创建都执行 `mesa_logi`（热路径日志）→ 已由 039 移除** |
| 034 | GPU 非缓存 AHB 导入 | 仅导入时改 flags | 无每帧开销；此前 A/B 无性能回退 |
| 035 | YU10 外部格式属性接受 | 仅 YU10 属性查询 | 可忽略 |
| 036 | YU10 图像/视图映射 | 仅 YU10 图像 | **发现：每个 YU10 图像创建打一条日志 → 已由 039 移除** |
| 037 | YU10 AHB 诊断日志 | **每次 AHB 导入 / 每次图像布局（无条件）** | **热路径日志，最终构建整体排除** |
| 038 | YU10 AFBC 打包格式映射 | 仅 YU10 格式分支 | 可忽略 |
| 039 | 移除 033/036 热路径日志 | — | 清理项 |

**关键发现**：诊断期补丁 033、036、037 在图像创建/导入热路径写 logcat。
其中 037 对每次 AHB 导入和每次图像布局都打日志；SystemUI/SF 与所有 App 的图像创建
都会经过这些路径，属于明显的 I/O/格式化开销与日志噪音。

## 最终性能清理构建

`diagnostic-build.json` 已切换为 13 个补丁的干净序列：

```
019 020 021 026 030 031 032 033 034 035 036 038 039
```

- 排除：022–025、027–029（诊断 tracing）、037（无条件热路径诊断日志）；
- 保留：全部功能修复（微信 acquire、共享性导入、AFBC/YU10 导入、kbase 生命周期等）；
- 新增 039：删除 033/036 遗留的每图像级 `mesa_logi`。

预期：图像创建/导入热路径不再有 logcat 写入；功能行为不变。

## 验证计划

1. CI 用新序列构建，确认补丁全部应用；
2. 对产物 `strings` 检查：不得出现 `movecert: afbc image`、
   `movecert: external YU10 image`、`movecert: ahb layout`、
   `movecert: image layout`、`movecert: layout init failed`；
3. 构建产物作为最终版驱动打包发布（版本号递增，避免与已发布 038 混淆）。

## 未验证/残余风险

- 最终清理驱动未在真机跑基准（用户已决定停用模块，手机已回滚 OEM）；
- 此前实测数据（1.0.0 系列）来自 034 驱动；038 仅做过功能验证，
  未做游戏/图形跑分对比；
- 清理只删除日志/诊断代码，不改变算法路径，理论上无功能回退风险。
