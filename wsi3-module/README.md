# PGKM10 Android 17 WSI3 实验模块

仅适用于已验证 SHA 的 PGKM10 Android 17 原厂 Vulkan / ColorX 组合。
这是 Vulkan 实验模块，不包含 OpenGL/EGL 更新，也不替换 32 位驱动。

修复组合：019 原生 DMA-BUF 导入、020 Kbase 同步路径、021 同步 FD 生命周期、
025 AFBC 数据区对齐；启用时仅打开 025 对齐兼容开关。系统硬件合成保持原设置。
安装时在手机上从已核对哈希的 OEM 库生成 ColorX 兼容副本；包内不包含 OEM 库。

安装默认关闭全局替换。Root 管理器的“操作 / Action”切换下次启动的开关，
显示 `enable_global=1` 后需要完整重启。再次操作切回 `0` 并重启即可回原厂；
也可禁用模块并重启。更新安装会重新设为关闭，不继承旧包的开启状态。

仅当机型、SDK、原厂库和新库的 SHA 都匹配才执行绑定；任一步失败尝试撤销本轮
绑定和属性。OTA 后库发生变化会拒绝激活，不能直接修改哈希绕过检查。
如果已临时挂载其他驱动，先恢复原厂并重启再安装。

WSI3 已通过独立 AFBC 偏移与图像/同步回归；临时运行验证不能代替开机挂载、
浏览器、其他游戏和长时间稳定性验证。开机日志保存在模块目录 `driver.log`。
此模块使用原有 PanVK 模块 ID，安装会替换原有模块。证书模块单独保留。
